# Devpost Submission Draft

## Additional Info

### What Google Cloud products did you use?

- Vertex AI with Gemini 2.5 Flash and Gemini 2.5 Flash-Lite for live camera direction, voice-intent interpretation, production recall, and alternate edit generation
- Vertex AI Gemini image generation for the cinematic scene plate
- Google Cloud Speech-to-Text for dialogue tracking and spoken director commands
- Google Cloud Text-to-Speech for the demo’s original synthetic dialogue
- Google Compute Engine for hosting the application
- Google Cloud IAM and service accounts for deployment authentication
- Google Cloud Billing budgets and alerts for cost controls

### Please list all other tools or products used

- Google Agent Development Kit (ADK) and Google Gen AI SDK
- ClickHouse and the official ClickHouse MCP server
- MediaMTX for authenticated WebRTC streaming and multicamera recording
- FFmpeg and ffprobe for virtual camera feeds, media processing, synchronization, and final video rendering
- OpenTimelineIO for edit timelines
- React, TypeScript, Vite, Lucide React, DM Sans, and Manrope
- FastAPI, Uvicorn, Pydantic, SQLite, NumPy, and SciPy
- Docker Compose, Nginx, and systemd
- Playwright and pytest for automated testing
- GitHub for source control
- Pexels open-licensed footage by cottonbro studio for the live-action demo source
